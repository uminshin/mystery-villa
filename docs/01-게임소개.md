# 그날 밤, 별장에서

> 폭풍으로 갇힌 외딴 섬의 별장. 15턴 안에 세 용의자 중 진범을 물증으로 지목하는
> LLM 기반 미스터리 텍스트 어드벤처.

---

## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 제목 | 그날 밤, 별장에서 |
| 장르 | 미스터리 텍스트 어드벤처 / 추리 시뮬레이션 |
| 플랫폼 | 웹 브라우저 (Streamlit) |
| 플레이 시간 | 1회 10~20분 |
| 인원 | 1인 |
| 언어 | 한국어 |

플레이어는 **의뢰를 받고 섬에 건너온 탐정**이다. 어젯밤 별장의 주인이 서재에서
숨졌고, 아침 배가 들어오기 전까지 아무도 섬을 떠날 수 없다. 지금 이 건물 안에
범인이 있다.

매 턴의 나레이션과 선택지는 **Claude가 실시간으로 생성**한다. 같은 사건을 다시
플레이해도 문장과 선택지는 매번 달라지지만, 진범과 단서 배치, 판정 규칙은
고정되어 있어 추리가 성립한다.

---

## 2. 게임 방법

### 목표

**진범을 지목하고, 그것을 물증으로 입증한다.**

지목만 맞히는 것으로는 부족하다. 진범을 가리키는 **결정적 단서 2개 이상**을
확보한 상태에서 지목해야 사건이 해결된다. 심증만 있으면 증거 불충분으로 풀려난다.

### 조작

마우스 클릭만 사용한다. 키보드 입력은 메모 작성에만 쓴다.

```
[홈]  사건을 맡는다
  ↓
[브리핑]  피해자 · 사망 추정 시각 · 타임라인 · 세 용의자 정보 확인
  ↓  수사를 시작한다
[수사]  선택지 3개 중 하나를 클릭 → 나레이션이 이어진다  (15턴)
  ↓  범인을 지목한다
[지목]  용의자 한 명을 지목 (또는 포기)
  ↓
[엔딩]  결과 · 동기 시나리오 · 평판 점수
```

### 세 가지 행동

| 행동 | 턴 소모 | 설명 |
| --- | --- | --- |
| **이동** | **0턴** | 다른 장소로 옮긴다. 자유롭게 오갈 수 있다 |
| **조사** | 1턴 | 현재 장소를 조사한다. 그 장소의 단서를 얻는다 |
| **심문** | 1턴 | 용의자에게 묻는다. 같은 인물을 여러 번 심문하면 진술이 한 층씩 열린다 |

이동이 무료인 이유는, 이동에도 턴을 쓰게 하면 15턴 안에 심문할 여유가
구조적으로 사라지기 때문이다.

### 장소 7곳

```
 2F   다락방  |  서재 ← 사건 현장
 1F   거실    |  침실
 B1   금고실
 옥외  정원    |  창고
```

장소마다 단서가 하나씩 숨어 있다. 총 7개 중 **4개가 진범을 가리킨다.**

### 두 가지 수치

- **의심도** — 그 인물이 범인이라는 심증. 조사·심문 결과로 움직인다.
  움직인 이유는 탐정 노트의 `비고` 열에 기록된다.
- **신뢰도** — 높으면 심문에서 더 많이 털어놓는다. **70 이상이면 숨긴 것까지
  흘린다.** 낮으면 적대적으로 답한다.

### 수사 기록

화면 오른쪽에서 세 가지를 확인한다.

- **용의자** — 의심도·신뢰도, 그리고 인물별 인상착의·태도. 단서를 인물과
  잇는 실마리가 여기 있다
- **단서** — 확보한 단서 목록과 상세
- **탐정 노트** — 턴별 행동 자동 기록 + **인물별 메모** (직접 작성)

### 종료 조건

| 조건 | 결과 |
| --- | --- |
| 진범 지목 + 결정적 단서 2개 이상 | **범인 검거** — 동기 시나리오가 공개된다 |
| 진범 지목 + 단서 부족 | 증거 불충분 · 석방 |
| 다른 사람 지목 | 오심 |
| 지목 포기 | 미제 사건 |

15턴을 모두 써도 화면이 강제로 넘어가지 않는다. 기록을 정리한 뒤 직접
`범인을 지목한다`를 눌러야 한다. 턴이 남아도 언제든 지목할 수 있다.

### 평판

사건이 끝나면 평판 점수가 누적되고 등급이 오른다.

| 항목 | 점수 |
| --- | --- |
| 판정 | 검거 50 / 증거 불충분 20 / 오심 5 / 미제 0 |
| 결정적 단서 | 1개당 8점 (최대 32) |
| 단서 전량 확보 | 6점 |
| 남긴 시간 | 1턴당 2점 (최대 16, **검거한 경우에만**) |

`수련 탐정` → 60점 `사설 탐정` → 150점 `이름이 알려진 탐정` → 280점 `명탐정`

속도 가산을 검거한 경우에만 주는 이유는, 그러지 않으면 "수사하지 않고 빨리 찍기"가
이득이 되기 때문이다. 아무 단서 없이 2턴에 진범을 찍으면 20점, 물증을 모아
입증하면 92점이다.

## 3. 실행 방법

### 준비물

- Python 3.10 이상
- Anthropic API 키 (선불 크레딧 필요)

### 설치

```bash
git clone https://github.com/uminshin/mystery-villa.git
cd mystery-villa
pip install -r requirements.txt
```

### API 키 설정

| OS | 명령 |
| --- | --- |
| Windows | `setx ANTHROPIC_API_KEY sk-ant-...` (설정 후 터미널을 새로 열어야 적용) |
| macOS / Linux | `export ANTHROPIC_API_KEY=sk-ant-...` |

키는 저장소에 포함되어 있지 않다. 환경변수로만 주입한다.

### 실행

```bash
python -m streamlit run app.py
```

브라우저가 자동으로 열린다. 열리지 않으면 `http://localhost:8501`로 접속한다.

> Windows에서 `streamlit run app.py`가 `CommandNotFoundException`으로 실패하면
> `python -m streamlit`을 사용한다. `streamlit.exe`가 설치되는 `Scripts` 폴더가
> PATH에 없는 경우가 있다.

### 소리

폭우 배경음과 행동별 효과음이 있다. 브라우저 자동재생 정책 때문에
**`수사를 시작한다`를 누른 뒤부터** 재생된다. 홈 화면과 수사 화면에서 끌 수 있다.

### API 호출 없이 화면만 확인하기

```bash
python -m streamlit run preview_ui.py
```

나레이션을 고정 텍스트로 대체한 개발용 하네스다. API 비용이 들지 않는다.

### 웹 배포에 대한 참고

이 게임은 Streamlit 서버 애플리케이션이므로 GitHub Pages(정적 호스팅)로는
배포할 수 없다. **Streamlit Community Cloud**를 사용하면 링크 클릭만으로 브라우저에서
바로 플레이할 수 있으며, `ANTHROPIC_API_KEY`는 플랫폼의 Secrets로 주입한다.

배포 시 고려할 점:

- API 키가 서버 측에 있으므로 방문자 수에 따라 API 비용이 발생한다
- 1회 플레이당 대략 15~20회의 API 호출이 일어난다
