## PDF 변환 방법

제출은 PDF여야 한다. 마크다운을 그대로 넘기면 안 된다.

**가장 쉬운 방법** — VS Code 확장 `Markdown PDF`로 우클릭 → Export (pdf).

**또는** Typora, Obsidian, Notion에 붙여넣고 PDF로 내보내기.

**또는** Pandoc:

```bash
pandoc docs/01-게임소개.md -o 게임소개.pdf --pdf-engine=xelatex -V mainfont="Malgun Gothic"
```

한글 폰트를 지정하지 않으면 글자가 빠진다.

### 1. 플레이 가능한 빌드 — **완료**

Streamlit Community Cloud에 배포했다. 링크 클릭만으로 플레이 가능하다.

- **플레이 URL**: https://mystery-villa.streamlit.app
- `ANTHROPIC_API_KEY`는 Streamlit Secrets(환경변수)로 주입 — 코드 수정 없이 동작
- API 키가 서버 측에 있으므로 방문자 수만큼 비용이 발생한다
  (1회 플레이 ≈ 15~20회 호출). Console에서 월 사용 한도 설정 권장.
- [01-게임소개.md](01-게임소개.md) 4절의 플레이 링크도 채움

남은 확인: 배포본에서 **첫 턴~엔딩 실제 한 판**을 돌려 나레이션 품질을 검증할 것
(자세한 내용은 [04-보완점.md](04-보완점.md) 5절).
