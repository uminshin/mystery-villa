## PDF 변환 방법

제출은 PDF여야 한다. 마크다운을 그대로 넘기면 안 된다.

**가장 쉬운 방법** — VS Code 확장 `Markdown PDF`로 우클릭 → Export (pdf).

**또는** Typora, Obsidian, Notion에 붙여넣고 PDF로 내보내기.

**또는** Pandoc:

```bash
pandoc docs/01-게임소개.md -o 게임소개.pdf --pdf-engine=xelatex -V mainfont="Malgun Gothic"
```

한글 폰트를 지정하지 않으면 글자가 빠진다.

## 남은 작업

### 1. 플레이 가능한 빌드 — **미해결**

Streamlit은 서버 애플리케이션이라 GitHub Pages로 배포할 수 없다.
**Streamlit Community Cloud**를 쓰면 링크 클릭만으로 플레이 가능하다.

- 배포 시 `ANTHROPIC_API_KEY`를 플랫폼 Secrets로 주입
- 저장소가 private이면 심사 계정(`dl_gameai_reviewer@nhn.com`)을 초대해야 한다
- API 키가 서버 측에 있으므로 방문자 수만큼 비용이 발생한다

배포 후 [01-게임소개.md](01-게임소개.md) 4절의 플레이 링크를 채워야 한다.
