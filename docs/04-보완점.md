## 1. 사운드 🔴 (팀 지목)

> "특히 사운드가 구리다."

근거가 되는 구현은 [`tools/make_audio.py`](../tools/make_audio.py)에 있다. 전부 numpy로
합성한 것이라 태생적 한계가 있다.

| 현상 | 근거 | 왜 구리게 들리나 |
| --- | --- | --- |
| 전반적으로 먹먹·저해상 | `RATE = 22050` ([make_audio.py:19](../tools/make_audio.py#L19)) | 샘플레이트가 CD의 절반. 고역이 ~11kHz에서 잘려 "옛날 라디오" 질감 |
| 공간감 없음 | 모노 출력 (`setnchannels(1)`, [make_audio.py:316](../tools/make_audio.py#L316)) | 좌우가 없어 평평하다. 별장이라는 공간이 안 느껴짐 |
| 효과음이 "무슨 소리인지 모르겠음" | 저자도 자인 — "합성으로 어색한 것은 추상적 신호로" ([make_audio.py:8-9](../tools/make_audio.py#L8)) | 이동=합성 나무 울림, 조사=셔터, 심문=**메트로놈**. 장면 소리(diegetic)가 아니라 추상 신호라 몰입을 깬다 |
| 음악(테마/BGM)이 사실상 없음 | 배경음은 `rain.wav` 앰비언스뿐 | 시작·긴장·엔딩을 받쳐 줄 선율이 없어 정적이 밋밋함 |
| 볼륨 조절 불가 | `LEVELS` 하드코딩 ([make_audio.py:26](../tools/make_audio.py#L26)) | on/off 토글만 있고 크기 조절이 없다 |

**제안**
- (가장 효과 큼) 합성을 고집하지 말고 **CC0 / 퍼블릭도메인 음원**(freesound.org CC0, Pixabay)으로
  교체 검토. 단, 제출 규정상 "외부 에셋 출처 명기"가 필요하니
  [02-AI활용-기술문서 8절](02-AI활용-기술문서.md#8-외부-에셋-및-오픈소스-출처)에 반드시 추가.
- 합성을 유지한다면 최소 `RATE`를 44100으로, 스테레오로. 심문 메트로놈은 시계추/괘종
  같은 **장면 안의 소리**로 바꾸면 덜 어색하다.
- **데드코드 정리**: [`rustle()`](../tools/make_audio.py#L294)(종이 넘기기)는 정의만 되어 있고
  아무 데서도 안 쓴다 — 조사음은 [`camera()`](../tools/make_audio.py#L181)로 대체됨
  ([main() 확인](../tools/make_audio.py#L329)). 지우거나 되살리거나 정리 필요.

## 2. 스토리 개연성 🔴 (팀 지목)

> "스토리의 개연성이 구리다."

트릭의 뼈대(비 그친 시각 + 정원 발자국 → C의 진술 붕괴)는 잘 짜여 있다. 다만 그
뼈대를 성립시키려고 끼워 넣은 설정들이 **역으로 개연성을 갉는다.** 근거는
[`game_state.py`](../game_state.py)와 [`gm.py`](../gm.py) 프롬프트다.

1. **탐정의 등장 경위가 공백.** 시스템 프롬프트는 "폭풍으로 뱃길이 끊긴 외딴 섬"
   이라면서 동시에 "의뢰를 받고 섬에 **건너온** 탐정" ([gm.py:122-124](../gm.py#L122))이라 한다.
   뱃길이 끊겼는데 어떻게 건너왔나? 엔딩에선 "아침 첫 배가 들어오고" ([game_state.py:457](../game_state.py#L457))
   라 하니, 탐정은 **폭풍 전에 이미 섬에 있었어야** 앞뒤가 맞는다. → 도착 경위 한 문장 필요.

2. **흉기 조달이 부자연스럽다.** 살해는 서재에서 일어났는데, 흉기(대리석 문진)를
   굳이 **잠긴 창고까지 가서** 가져온다 ([game_state.py:371-379](../game_state.py#L371)).
   서재·거실에 다른 둔기가 없었다는 근거가 게임 안에 없다. "하필 그 문진이어야 할"
   필연성이 약해서, **단서(창고 c7·정원 c4)를 먼저 정해 놓고 동기를 나중에 끼운** 인상이 남는다.

3. **20분 왕복이 빠듯하다.** 비 그침 23:20 → 정원 지나 창고 자물쇠 열고 문진 꺼내
   → 되돌아와 → 서재에서 살해 → 사망 추정 23:40. 저자도 "20분이 이 사건의 전부다"
   ([game_state.py:379](../game_state.py#L379))라고 자인. 나레이션이 이 시간표를 못 받쳐 주면 무너진다.

4. **레드헤링 A가 진범 C보다 더 범인 같다.** A는 물증 2개(위스키 잔 지문 조작 c1,
   "A에게는 한 푼도" 유언장 c2)가 **직접** 가리키고 알리바이도 없다. 반면 C의 결정타는
   "발자국 vs 진술 모순"이라 **추론 한 단계가 더** 필요하다. 초보 플레이어가 A 물증 2개로
   A를 지목하면 `WRONG`([game_state.py:480](../game_state.py#L480))이 뜨는데, 체감상 억울할 수 있다.
   → 공정성/난이도 튜닝 대상. (의도된 장치라도 "속았다"가 아니라 "억울하다"가 되면 실패)

5. **`c4` 발자국이 신발 종류만으로 C를 단독 지목.** 단서 상세 "굽이 얇은 신발"
   ([game_state.py:108](../game_state.py#L108)) + C 외형 "굽이 얇은 검은 구두"([game_state.py:55](../game_state.py#L55))
   = 단서 하나가 인물을 거의 확정한다. 여러 단서를 **종합**하는 추리의 맛이 줄어든다.

6. **수면제 병(`c6`)의 의미가 붕 뜬다.** "그날 밤 그녀 자신을 위한 것"
   ([game_state.py:384](../game_state.py#L384))이라는데, 살인 후 자살 시도인지·피해자에게 먹이려 한
   건지 게임에서 불명확하다. 해석의 여지를 남기려던 게 그냥 미완으로 읽힌다.

**제안**: 진실 시나리오([CULPRIT_STORY_SECTIONS](../game_state.py#L345))를 팀이 소리 내어
한 번 통독하며 "물리적으로/심리적으로 말이 되나"를 문장 단위로 점검. 특히 2·3번은
"왜 서재의 물건이 아니라 창고 문진인가"에 한 줄 근거를 넣으면 대부분 해소된다.

## 3. 버그

### 3-1. 소리를 꺼도 빗소리가 계속 난다 — ✅ 수정 완료
- **현상**: 소리 토글을 off 해도 배경 빗소리(BGM)가 멈추지 않았다. (효과음은 정상)
- **원인**: [`render_bgm()`](../app.py#L168)이 컨테이너 키를 `"bgm"`으로 **고정**해
  ("턴마다 리셋 방지" 목적) 이미 `loop` 재생 중인 `<audio>` 노드가 off 이후에도
  DOM에 살아남았다. "리셋되지 않게"와 "끄면 멈추게"가 충돌.
- **수정**: 컨테이너 키를 소리 상태(`sound_enabled`)에 묶었다. 켜져 있으면 키가
  `bgm-on`으로 유지돼 턴마다 리셋되지 않고, 끄면 `bgm-off`로 바뀌며 옛 노드가
  언마운트돼 즉시 멈춘다. (커밋 `0f43eb9`, [app.py:168](../app.py#L168))

## 4. 게임플레이 · UX 🟡

- **자유 입력이 없다.** 버튼 3개만 제시되고 [`st.chat_input`]은 미구현
  (README "다음에 붙일 만한 것"에도 명시). 추리 게임인데 "묻고 싶은 것을 직접 못 묻는다."
- **재플레이 가치가 낮다.** 진범은 항상 C 고정, 단서 배치도 고정([game_state.py:76](../game_state.py#L76)).
  2회차부터는 정답을 알고 시작하므로 추리가 사라지고 문장 변주만 남는다.
  → 진범/배치를 시드로 섞는 모드, 또는 제2화(현재 "준비 중") 추가.
- **진행 상태 저장이 없다.** `st.session_state` 메모리에만 있어 **새로고침/탭 닫기 = 판 소실**.
  실수로 새로고침 한 번이면 15턴이 날아간다.
- **모바일 레이아웃.** 게임 화면이 2단 컬럼([app.py:679](../app.py#L679))이라 좁은 화면에선
  위아래로 쌓인다. 실제 폰에서 무대·수사기록 순서와 스크롤 양 점검 필요.

## 5. 나레이션 · 프롬프트 품질 🟡

- **실제 플레이 품질이 아직 미검증.** 배포는 됐고 시작 화면 렌더까지는 확인했으나,
  개발 중 실제 API 키가 없어 **첫 턴부터 엔딩까지 한 판**을 돌려 나레이션·선택지
  품질을 확인한 적이 없다. (이게 가장 급한 QA)
- **모델·effort는 비용에 맞춰 조정됨.** GM 모델은 `claude-sonnet-5`, `effort`는 `low`
  ([gm.py](../gm.py))로 판당 비용을 낮춰 두었다. 나레이션 품질이 아쉬우면 effort를
  `medium`으로 올리거나 모델을 `claude-opus-5`로 되돌리면 된다(각각 한 줄).
- **응답 잘림 위험.** `MAX_TOKENS = 8000`이 thinking+텍스트 합산 상한([gm.py:33](../gm.py#L33)).
  사고가 길어지면 `max_tokens`로 잘려 GMError → "다시 시도"를 반복하게 될 수 있다.
- **반복 심문의 공허함.** 3층 진술 소진 후에는 "태도 변화만" 묘사하고 수치는 거의
  안 움직인다([gm.py:154-156](../gm.py#L154)). 플레이어 입장에선 턴만 버린 느낌이 들 수 있다.

## 6. 기술 · 배포 · 비용 🟡

- **공개 URL + 서버 측 키 = 비용 노출.** 1회 플레이당 15~20회 호출, 모델은 `opus-5`.
  접근 제어가 없어 링크만 알면 누구나 크레딧을 태울 수 있다.
  → Console에서 **월 사용 한도** 설정, 또는 간단한 접근 비밀번호(`st.secrets` + 입력 게이트),
  심사 종료 후 앱 내리기.
- **자동재생 제약.** 브라우저가 조작 전 재생을 막아, 빗소리는 시작 버튼을 누른 뒤에만
  나온다([app.py:171-172](../app.py#L171)). 정상 동작이지만 "왜 처음엔 소리가 없지?" 오해 소지.
